# Guides

Step-by-step guides for developing and migrating Odoo modules with Odoo Build.

## Mint System modules

Modules developed and maintained by [Mint System](https://www.mint-system.ch/) in the `addons/` folder.

- [Develop a Mint System module](develop-mint-system-module.md): From specification to the final commit.
- [Migrate a Mint System module](migrate-mint-system-module.md): Move a module to the next Odoo version.

## OCA modules

Modules maintained in the [Odoo Community Association](https://odoo-community.org/) repositories in the `oca/` folder.

- [Develop an OCA module](develop-oca-module.md): Create a new module for an OCA repository.
- [Migrate an OCA module](migrate-oca-module.md): Migrate a module and submit the pull request.

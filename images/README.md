# Images

The Odoo Build project maintains these container images:

[Mint System Odoo](/images/odoo/): A better Odoo image.

[Mint System Odoo CLI](/images/odoo-cli/): Image to run the odoocli.

[Mint System Odoo Mailgate](/images/odoo-mailgate/): Receive and forward emails to Odoo.

[Mint System Odoo Upgrade](/images/odoo-upgrade/): Image to run the Odoo Enterprise upgrade script.
